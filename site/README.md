# לבחור נכון — סיגלית שושן · אתר בעיצוב שמנת

אתר נחיתה (Landing Page) חד-עמודי, RTL בעברית, עבור סיגלית שושן — אימון קריירה וחיים.
התוכן זהה לאתר המקור, אך העיצוב נבנה מחדש לחלוטין בגווני **שמנת עדינים**, עם
התמונות האמיתיות והלוגו.

## צפייה
פותחים את `index.html` בדפדפן. אין צורך בבנייה או שרת — HTML/CSS/JS סטטי בלבד.

## מבנה
- `index.html` — כל התוכן והמבנה
- `styles.css` — העיצוב (פלטת שמנת, טיפוגרפיה, רספונסיביות)
- `script.js` — תפריט מובייל, אנימציות גלילה, אקורדיון השאלות
- `assets/` — תמונות ולוגו:
  - `hero.jpg` — תמונת הכיסא הצהוב (ראש הדף)
  - `about.jpg` — תמונת הספה (אודות)
  - `lecture-1.jpg`, `lecture-2.jpg` — תמונות הרצאה (מרצה ומנחת סדנאות)
  - `portrait-mic.jpg` — תמונת מיקרופון (המלצות)
  - `logo-mark.png` — אמבלם הלוגו (רקע שקוף)
  - `logo-full.png` — לוגו מלא
  - `favicon.png` — אייקון הדפדפן
