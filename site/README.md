# לבחור נכון — סיגלית שושן · אתר בעיצוב שמנת

אתר נחיתה (Landing Page) חד-עמודי, RTL בעברית, עבור סיגלית שושן — אימון קריירה וחיים.
התוכן זהה לאתר המקור, אך העיצוב נבנה מחדש לחלוטין בגווני **שמנת עדינים** (במקום החום/זהב הכהה המקורי).

## צפייה
פותחים את `index.html` בדפדפן. אין צורך בבנייה או שרת — HTML/CSS/JS סטטי בלבד.

## מבנה
- `index.html` — כל התוכן והמבנה
- `styles.css` — העיצוב (פלטת שמנת, טיפוגרפיה, רספונסיביות)
- `script.js` — תפריט מובייל, אנימציות גלילה, אקורדיון השאלות
- `assets/portrait.svg` — מציין מיקום לתמונה של סיגלית

## להחלפה לפני העלאה לאוויר
1. **תמונה** — החליפו את `assets/portrait.svg` בתמונה אמיתית של סיגלית
   (למשל `assets/portrait.jpg`) ועדכנו את ה-`src` בתגית `<img>` בסקשן "אודות".
2. **פרטי קשר** — טלפון `050-000-0000` ואימייל `sigalit@coaching.co.il` הם
   ערכים מהאתר המקורי; עדכנו לפרטים האמיתיים.
3. **טופס יצירת קשר** — כרגע הטופס דקורטיבי (ללא שליחה בפועל). חברו אותו
   לשירות (Formspree / מייל / API) כדי לקבל פניות.
4. **תשובות לשאלות נפוצות** — באתר המקור הוצגו רק השאלות (ללא תשובות גלויות).
   נוסחו כאן תשובות קצרות והגיוניות — מומלץ לעבור עליהן ולהתאים.
